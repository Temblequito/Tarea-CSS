Módulo 1: Fundamentos de CSS

CSS es un lenguaje de estilos utilizado para controlar la presentación de documentos HTML. Permite separar la estructura del diseño visual, facilitando el mantenimiento y la reutilización del código.

Conceptos Aprendidos en la Lección

  • Separación de contenido y presentación
  • Tipos de CSS: Externo, Interno y en Línea
  • Sintaxis básica de Selector, Propiedad y Valor
  • Diferencia entre selectores de etiqueta, clase e ID
